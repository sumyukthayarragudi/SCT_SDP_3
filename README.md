# 🧩 Sudoku Solver

A simple and interactive web-based Sudoku Solver built using HTML, CSS, and JavaScript.

## Features

- 🧩 Provides an interactive 9×9 Sudoku grid
- 🔢 Allows the user to enter Sudoku numbers
- 🧠 Solves Sudoku puzzles using the Backtracking Algorithm
- ✅ Validates the entered Sudoku puzzle
- ⚠️ Detects invalid Sudoku inputs
- ❌ Detects puzzles that have no possible solution
- 🎯 Keeps the original numbers visually different from solved numbers
- 📋 Provides an example Sudoku puzzle
- 🧹 Allows the user to clear the puzzle
- 📱 Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter the known numbers of a Sudoku puzzle into the 9×9 grid.
2. Click the **Solve Sudoku** button.
3. The Backtracking Algorithm checks the puzzle and finds a valid solution.
4. The original numbers remain highlighted separately from the numbers generated by the solver.
5. Click **Load Example** to load a sample Sudoku puzzle.
6. Click **Clear** to remove all numbers and start again.
